# RankJee Deployment Guide (IP mode + Domain mode)

Server IP (current): `161.97.146.14`
Repo: `https://github.com/kriyespro/sd-rankjee2026.git`
Branch: `main`

Use this exact flow for local -> GitHub -> live server.

## 1) Local machine: commit and push to GitHub
```bash
cd ~/Desktop/sd-rankjee2026
git status
git add .
git commit -m "Deploy: <your change summary>"
git push origin main
```

## 2) Live server: first-time setup (if repo not present)
```bash
ssh root@161.97.146.14
cd /root
git clone https://github.com/kriyespro/sd-rankjee2026.git
cd sd-rankjee2026
```

## 3) Live server: update code (normal deployment)
```bash
ssh root@161.97.146.14
cd /root/sd-rankjee2026
git pull origin main
git log -1 --oneline
```

## 4) Production .env (choose ONE mode)
```bash
cd /root/sd-rankjee2026
cp -n .env.production.example .env
nano .env
```

### Mode A: Domain + HTTPS (recommended for production)
Use this config when site is served from `https://rankjee.com`:
```env
DEBUG=False
SECRET_KEY=replace-with-strong-secret
ALLOWED_HOSTS=rankjee.com,www.rankjee.com,161.97.146.14,127.0.0.1,localhost

DATABASE_URL=postgres://postgres:postgres@db:5432/rankjee_db
DB_CONN_MAX_AGE=600

REDIS_URL=redis://redis:6379/0
REDIS_CACHE_URL=redis://redis:6379/2
CELERY_BROKER_URL=redis://redis:6379/0
CELERY_RESULT_BACKEND=redis://redis:6379/0
USE_REDIS_CACHE=1

SITE_BASE_URL=https://rankjee.com
CSRF_TRUSTED_ORIGINS=https://rankjee.com,https://www.rankjee.com
```

### Mode B: IP-only + HTTP (temporary testing only)
Use this config when no domain/SSL is configured:
```env
DEBUG=False
SECRET_KEY=replace-with-strong-secret
ALLOWED_HOSTS=161.97.146.14,127.0.0.1,localhost

DATABASE_URL=postgres://postgres:postgres@db:5432/rankjee_db
DB_CONN_MAX_AGE=600

REDIS_URL=redis://redis:6379/0
REDIS_CACHE_URL=redis://redis:6379/2
CELERY_BROKER_URL=redis://redis:6379/0
CELERY_RESULT_BACKEND=redis://redis:6379/0
USE_REDIS_CACHE=1

SITE_BASE_URL=http://161.97.146.14:8889
CSRF_TRUSTED_ORIGINS=http://161.97.146.14:8889
```

Save in nano: `Ctrl+O`, `Enter`, `Ctrl+X`

IMPORTANT:
- Do not mix Mode A and Mode B values.
- If browser URL is `https://rankjee.com`, `SITE_BASE_URL` and `CSRF_TRUSTED_ORIGINS` must also be HTTPS domain values.

## 5) Docker deploy commands (clean deploy)
```bash
cd /root/sd-rankjee2026
docker compose down --remove-orphans
docker compose up -d --build
docker compose ps
docker compose logs web --tail=120
```

## 6) If DB got corrupted during failed setup (fresh reset)
WARNING: this removes all database data.
```bash
cd /root/sd-rankjee2026
docker compose down -v --remove-orphans
docker volume ls | awk '/sd-rankjee2026/ {print $2}' | xargs -r docker volume rm
docker compose up -d --build
docker compose ps
docker compose logs web --tail=120
```

## 7) Create superuser + import content bundle
```bash
cd /root/sd-rankjee2026
docker compose exec web python manage.py createsuperuser
docker compose exec web ls -la /app/rankjee_full.json
docker compose exec web python manage.py import_content_bundle
```

## 8) Quick health checks
```bash
docker compose ps
docker compose logs web --tail=80
curl -I http://127.0.0.1:8889
curl -I http://161.97.146.14:8889
```

If using domain mode:
```bash
curl -I https://rankjee.com
```

## 9) Verify settings loaded by Django
```bash
docker compose exec web python manage.py shell -c "from django.conf import settings; print(settings.DEBUG); print(settings.ALLOWED_HOSTS); print(settings.SITE_BASE_URL)"
```
