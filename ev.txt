Razorpay integration (code behaviour — updated)
-----------------------------------------------
Backend (`payments/views.py`, `payments/services.py`, `payments/urls.py`):
  • POST `/payments/order/<plan_id>/` — creates Razorpay order (amount in paise), adds `receipt`,
    enforces minimum 100 paise for live mode; maps Razorpay errors to 400 / 401 / 500 where appropriate.
  • POST `/payments/verify/` — form fields: razorpay_order_id, razorpay_payment_id, razorpay_signature;
    requires payment id + signature for live mode; uses SDK signature verification; does not mark paid
    on mismatch (order → FAILED).
  • Dummy mode: DEBUG + missing keys, or `RAZORPAY_USE_DUMMY=1` — local confirm flow without keys.

Frontend (`templates/payments/plans.jinja`):
  • Loads `https://checkout.razorpay.com/v1/checkout.js`, opens modal, verifies via fetch + CSRF.
  • Handles JSON parse errors, `payment.failed`, and modal dismiss hook.

Post-payment redirect (`payments/views.py` — `_exam_subscription_success_url`):
  • Staff or superuser → `/admin/?paid=1` (command centre).
  • Everyone else → `/assessment/?paid=1` (diagnostic catalog).

UX confirmations:
  • `templates/assessment/test_list.jinja` — banner when `paid=1`.
  • `templates/dashboard/admin_dashboard.jinja` — banner when `paid=1` for staff.

Settings (`rankjee/settings.py`): reads `RAZORPAY_KEY_ID`, `RAZORPAY_KEY_SECRET`, `RAZORPAY_WEBHOOK_SECRET`
from environment (`python-dotenv` loads `.env`).

Database migrations (Docker)
---------------------------
After pull on the server, apply Django migrations inside the `web` container:

  cd ~/sdrankjee2026
  docker compose exec web python manage.py migrate

If the stack was recreated from scratch:

  docker compose up -d --build
  docker compose exec web python manage.py migrate

Local (SQLite):

  cd ~/Desktop/sd-rankjee2026
  python3 manage.py migrate

Host Nginx (MindMap on 8080 frees host :80)
-------------------------------------------
1) DNS: A records for rankjee.com and www → 161.97.146.14
   Cloudflare proxied: SSL/TLS = Full (strict). DNS-only: traffic hits VPS directly.
2) Create /etc/nginx/sites-available/rankjee.com — paste the two server { } blocks below (no leading #), then:

server {
    listen 80;
    listen [::]:80;
    server_name rankjee.com www.rankjee.com;
    return 301 https://$host$request_uri;
}
server {
    listen 443 ssl http2;
    listen [::]:443 ssl http2;
    server_name rankjee.com www.rankjee.com;
    ssl_certificate     /etc/letsencrypt/live/rankjee.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/rankjee.com/privkey.pem;
    client_max_body_size 25m;
    location / {
        proxy_pass http://127.0.0.1:8889;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

  sudo ln -sf /etc/nginx/sites-available/rankjee.com /etc/nginx/sites-enabled/rankjee.com
  sudo nginx -t && sudo systemctl enable --now nginx && sudo systemctl reload nginx
3) cd ~/sdrankjee2026 && git pull origin main && docker compose exec web python manage.py migrate && docker compose up -d --force-recreate web
