# 🧩 PHASE 1: MVP (0 → 3 Months)

### 🎯 Goal: Validate core loop → *“Test → Learn → Retest → Earn (basic)”*

## 🔧 Core Features (Must Build Only)

### 1. User System

* Signup / Login (Email + Google)
* Basic profile (skills, progress)

---

### 2. Test Engine (Core Differentiator)

* MCQ-based diagnostic test
* Tag questions by:

  * Skill
  * Difficulty
  * Concept
* Output:

  * Weak areas (IMPORTANT)

👉 Architecture:

* `Question Bank (DB)`
* `User Attempt Logs`
* `Weak Area Engine (rule-based)`

---

### 3. Micro Learning Module

* Admin uploads:

  * Video (30–120 sec)
  * 3–5 questions
* Show content based on weak areas

👉 Keep it SIMPLE:

* No AI yet
* Use **rule-based mapping**

---

### 4. Retest Engine

* After learning → retest same concept
* Lock progression until:

  * Score ≥ 80%

👉 Logic:

```
if score < 80:
   repeat learning
else:
   unlock next skill
```

---

### 5. Basic Dashboard

* Progress %
* Weak skills
* Completed topics
* Daily streak

---

### 6. Basic Earning System (VERY IMPORTANT FOR VALIDATION)

* Simple tasks:

  * Share affiliate link
  * Submit proof
* Manual approval (initial)

👉 DO NOT automate early → avoid complexity

---

### 7. Admin Panel (Custom Django Admin)

* Upload:

  * Skills
  * Questions
  * Videos
* View:

  * User progress
  * Earnings

---
