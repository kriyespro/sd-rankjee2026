# Exact root cause

Nginx logs confirm application timeout:

```text
upstream timed out (110: Unknown error) while reading response header from upstream
```

Meaning:

```text
Nginx → forwarded request to Gunicorn
Gunicorn accepted request
Django took too long
Nginx timed out
```

This is an **application-layer latency issue**.

# High-probability root causes

## 1. Blocking external HTTP/API calls

Search for:

```python
requests.get(...)
requests.post(...)
httpx.get(...)
urllib.request(...)
socket calls
```

Bad pattern:

```python
requests.get(url)
```

Good:

```python
requests.get(url, timeout=10)
```

Check:

* Google auth integration
* Razorpay
* SMTP
* quote generation
* DNS lookup
* server pricing APIs

---

## 2. Django admin query inefficiency

Admin endpoints timing out strongly suggest ORM inefficiency.

Audit:

```python
ModelAdmin.list_display
ModelAdmin.get_queryset()
@property in admin display
__str__()
foreign key traversal
count() per row
```

Fix with:

```python
select_related()
prefetch_related()
```

---

## 3. Heavy middleware / context processors

Because homepage/login also affected.

Check middleware for:

* DB lookups
* API calls
* quote calculations
* user dashboard metrics
* notification counters

---

## 4. Gunicorn worker starvation

If requests block, 3 workers can be exhausted.

Symptoms:
random 504 across unrelated routes.
