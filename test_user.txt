## Parent<->Student link demo — proves read-only visibility only after student approves
- Use `demo_parent` (see above) and `demo_student` — log in as `demo_parent`, go to `/users/family/`,
  request a link by entering `demo_student` (username or email).
- Log in as `demo_student` and go to `/users/family/` to approve (or reject) the request.
- Once approved, log back in as `demo_parent` and `/users/family/` shows demo_student's exam attempts,
  LMS course enrollments, XP, streak, and daily attendance log — read-only, nothing the student couldn't
  already see about themselves. Before approval, the parent sees the link as "Pending approval" with no
  progress data.
- `demo_student` has 3 sample attendance entries seeded (self-logged via `/dashboard/daily-class-log/`) so
  the parent view's "Attendance (self-reported)" chips (green=Present, red=Absent) have something to show.
