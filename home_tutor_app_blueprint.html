Features by module — click to expand
Tutor discovery & matching
How parents find the right tutor
▶
Requirement-based search
Parent enters subject, class/board (CBSE/ICSE/State), area, budget — app returns ranked tutors matching all criteria.
Smart filters
Filter by gender preference, language of teaching, online/offline, fee range, rating, availability day/time.
Distance-based sorting
Show tutors nearest to parent's pincode first. Distance displayed on tutor card (e.g. "2.3 km away").
Requirement post (reverse search)
Parent posts requirement publicly — matching tutors in the area get notified and can apply. Tutor comes to parent, not just other way round.
Tutor comparison
Select 2–3 tutors and view side-by-side on fee, experience, ratings, and subjects.
Saved / shortlisted tutors
Parent can save tutors to a shortlist before requesting demo — compare later.
Tutor profile & verification
Trust is the product — verification is everything
▶
Rich tutor profile
Photo, bio, subjects, boards, classes taught, medium (English/Hindi/Gujarati), years of experience, education qualification, current occupation.
Aadhar-based identity verification
Tutor uploads Aadhar + selfie. Admin verifies. Verified badge shown on profile — parents trust this most.
Education document upload
Degree / marksheet upload. Admin verifies claimed qualifications before profile goes live.
Intro video (60 sec)
Tutor records a short self-introduction. Parents watch before requesting demo — massively increases conversion.
Availability calendar
Tutor sets available days and time slots. Parents only see tutors available when they need them.
Student reviews & ratings
Only verified past students can leave reviews. Star rating (1–5) + written review. Fake review prevention built in.
Teaching area / travel radius
Tutor sets max distance willing to travel. Only shown in searches within that radius.
Demo class & booking
Trial before commitment — reduces dropout
▶
Demo class request
Parent sends demo request with preferred date/time. Tutor accepts or proposes alternate time.
Demo reminders
Both parent and tutor get WhatsApp + push notification 1 day before and 1 hour before demo.
Tutor live location share
On demo day, tutor can share live location to parent — safety feature, also shows they're on the way.
Post-demo decision prompt
After demo is marked done, both parent and tutor are asked: "Want to continue?" — if both say yes, booking is created.
Schedule setup
On confirmation, parent and tutor agree on recurring days, time, subjects. Saved as active schedule in app.
1 free demo per tutor per student
System enforces one free demo — prevents misuse. Second demo with same tutor is paid at ₹99.
Session tracking & attendance
Every class logged — full transparency
▶
Session mark done (tutor)
Tutor marks each class done from their app. Parent gets notification — "Today's class marked complete."
Attendance calendar (parent)
Parent sees monthly attendance calendar — green = class happened, red = missed, yellow = holiday.
Session notes
Tutor can add brief notes after each session — "Covered Chapter 3, homework assigned." Parent can see this.
Missed class reason & makeup
If tutor cancels, they must give reason and propose makeup class. Excessive cancellations flagged by admin.
Monthly session count
Total classes done this month shown to both parties — used for fee calculation if per-class billing model.
Holiday marking
Tutor or parent can mark upcoming holidays in advance. Both sides see upcoming breaks on calendar.
Payments & earnings
Money flow — parent pays, tutor earns, you take cut
▶
Monthly fee collection (parent)
Parent pays monthly fee via UPI, card, or net banking through Razorpay. Auto-pay option for recurring payment.
Platform commission deduction
You take 10–15% of fee. Tutor gets 85–90%. Deduction shown transparently in tutor's payout screen.
Tutor payout (monthly)
On 5th of every month, payout released to tutor's linked bank account via IMPS/NEFT. Tutor gets notification.
Fee reminder to parent
Auto-reminder 3 days before fee due date via WhatsApp and push notification. Reduces payment delays.
Refund on early termination
If parent stops mid-month, proportional refund calculated based on classes held. Admin approves.
Invoice / receipt download
Parent can download fee receipt as PDF. Useful for tax exemption claims under 80C.
Admin revenue dashboard
Total GMV, platform commission earned, tutor payouts pending, monthly growth — all in one view.
Communication & safety
In-app chat + safety features for home visits
▶
In-app chat (masked)
Parent and tutor chat inside app — real phone numbers never shared. Platform controls communication and has dispute record.
File & photo sharing in chat
Share study material, sample papers, homework photos inside chat. Keeps everything in one place.
Tutor photo shown before visit
Parent sees tutor's verified photo before they arrive. Safety feature — important for families.
Report tutor / report parent
Either side can report the other. Goes to admin queue with both accounts flagged until resolved.
SOS / emergency contact
Tutor can share live location to a trusted contact during visits. Safety for female tutors visiting new homes.
Admin support chat
Both parent and tutor can raise a support ticket. Admin responds within app.

Tutor profile + Aadhar verification
The foundation of trust. No verification = no parent trust = no bookings. Non-negotiable.
Parent requirement + tutor search
Core discovery. Must work with at least subject + area + class filters.
Demo class request + confirmation flow
The main conversion event. Both sides must confirm — without this there's no booking.
Monthly fee payment via Razorpay
Your revenue engine. Must work before launch — this is how you make money.
Session attendance marking
Tutor marks class done — parent is notified. Basic version: just a button. No notes yet.
Tutor payout to bank (manual in MVP)
Pay tutors manually via NEFT for first 3 months. Automate in V2 once volume justifies it.
Admin verification panel
You need to approve tutors before they go live. Simple web dashboard is enough for MVP.
In-app chat (basic)
Text only, no file sharing yet. Essential for coordination without sharing real phone numbers.
Save for V2

Intro video upload for tutors

Tutor live location share on demo day

Tutor comparison side-by-side
Useful UX but not blocking. Parents manage fine with individual profiles for now.
Session notes & study material sharing
Parents like this but it's not why they pay. Attendance log is enough for V1.
80C fee receipt PDF
Tax season feature — easy to add with a PDF template, but not urgent at launch.
One honest warning
This is a marketplace — chicken-and-egg problem is real
You need tutors to attract parents, and parents to attract tutors. Before you build anything, manually onboard 20–30 verified tutors in one area of Ahmedabad. Then open to parents. Never launch both sides simultaneously with zero supply — parents will search, find nothing, and never return.
